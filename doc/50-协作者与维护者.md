# 协作者与维护者

想要达到最理想的维护状态，每一个 recipe 都需要有专人长时间维护。**我们的代码里使用了 recipe (某个菜的烹饪方法) 这个词，因而整个项目便和 "饮食" 有关，比如 `menu`: 汇集了所有的 target 的菜单。因此，我们的维护者和贡献者身份依然使用了这个惯例：**

1. **Chef**

    主厨: 一个 recipe 的主要作者

2. **Saucier**

    调味：一个 recipe 的次要贡献者
